# Kid Timeline View

Visualize your kids' ages over time as a timeline, with bands for age stages (Child, Teen, Driving, College, Adult) and school-year markers.

Built with [Vite](https://vitejs.dev/), [vis-timeline](https://github.com/visjs/vis-timeline), and [vis-data](https://github.com/visjs/vis-data). Plain JS, no framework.

## Prerequisites

- Node.js (v18+ recommended)
- npm

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Starts Vite dev server with hot reload.

## Build

```bash
npm run build
```

Outputs production build to `dist/`.

## Preview production build

```bash
npm run preview
```

Serves the `dist/` build locally to sanity-check before deploy.
